# S1.4 — Runtime State Revision and CAS


## Goal

Prevent silent stale whole-document runtime-state overwrite with PostgreSQL revision/CAS and controlled conflict behavior.

## Required behavior

- Load runtime state with revision.
- Save only when expected revision matches.
- Successful save increments revision.
- Zero updated rows is a conflict, never success.
- Conflicted/stale processor does not send final Telegram response or mark update complete.
- Whole `state_json` may remain physical format only under CAS.
- Retry/defer behavior is bounded and does not spam external side effects.

## In scope

State revision migration, repository contract, graph load/persist integration, conflict result mapping, no-send guard, repository/service/integration tests.

## Out of scope

Full path-level state ownership decomposition (S5), prompt-injection hardening, manager tenant binding, close lifecycle.

## Task acceptance criteria

- S1.4-AC-01: stale revision update affects zero rows and returns explicit conflict.
- S1.4-AC-02: current revision update succeeds once and increments deterministically.
- S1.4-AC-03: conflict after LLM output creates no final outbound response.
- S1.4-AC-04: lease loss and CAS conflict converge on controlled retry/defer.
- S1.4-AC-05: existing rows receive safe initial revision.
- S1.4-AC-06: all production whole-state writers use or are safely isolated from the new revision contract.

## Required QA design

Inventory every state writer, simultaneous graph/service writes, migration of existing rows, reset paths, retry after conflict, stale snapshots of ticket-resolution/analytics fields, and regression of read APIs.

## Expected test levels

Migration/repository integration, graph persistence integration, no-send service test, concurrency test involving independent connections.

## Rollback/degraded behavior

Keep thread lease active. Conflicted work remains retryable/deferred or routes to controlled manager handling. Do not revert to last-write-wins.

## Documentation updates

Actual runtime-state persistence, R2 remediation state, S5 remaining ownership debt, traceability and evidence.
