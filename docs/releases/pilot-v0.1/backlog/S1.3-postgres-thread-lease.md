# S1.3 — PostgreSQL Thread Execution Lease


## Goal

Provide PostgreSQL-authoritative same-thread execution ownership for client conversation processing.

## Required behavior

- Lease scope is project/thread.
- Random owner token, expiry, atomic claim, owner-guarded renew/release, and expiry recovery.
- No pooled connection is held across long graph/LLM execution.
- At most one active owner for a thread.
- A stale owner cannot renew, release, complete, or authorize final response.
- Failure to acquire produces controlled defer/retry, not parallel graph execution.
- Redis may optimize coordination but cannot be authority.

## In scope

Lease schema/repository/port, orchestrator integration, heartbeat/renewal/cancellation behavior, concurrency and recovery tests, composition wiring.

## Out of scope

Runtime state CAS implementation, full state ownership decomposition, R17, close lifecycle, runtime-limit accounting.

## Task acceptance criteria

- S1.3-AC-01: two workers cannot hold valid lease for one project/thread.
- S1.3-AC-02: different threads may proceed independently.
- S1.3-AC-03: stale owner cannot renew/release after takeover.
- S1.3-AC-04: process crash permits recovery only after expiry.
- S1.3-AC-05: long processing renews without holding one DB connection.
- S1.3-AC-06: Redis outage does not weaken thread ownership.
- S1.3-AC-07: production composition cannot fall back to `NullThreadLock` for pilot traffic.

## Required QA design

Cover claim races, lease boundary time, clock assumptions, renewal delay, process cancellation, database transient failure, stale release, multiple processes, and worker shutdown.

## Expected test levels

PostgreSQL concurrency integration, orchestrator tests with controlled clock, composition tests, process-level recovery when feasible.

## Rollback/degraded behavior

Reduce concurrency, defer thread processing, or pause unsafe processing. Never return pilot traffic to `NullThreadLock`.

## Documentation updates

Actual composition, R23 remediation, R2 partial protection, traceability and acceptance evidence.
